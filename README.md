# Projet Hostbook SAÉ-203

Notre entreprise reinvente la facon d'utiliser un ordinateur.

Notre concept
Nous vendons des ordinateurs vides a tres bas prix. Ils n'ont pas de systeme d'exploitation ni de composants onereux. Pourquoi ? Parce que toute la puissance se trouve sur Internet, directement dans nos serveurs !

Comment ca marche ?
Des que vous allumez votre machine, elle se connecte au Cloud Hostbook. Grace a nos abonnements a la carte, vous choisissez la puissance dont vous avez besoin :

Le Pack Bureautique : Simple et efficace. Vos applications de travail sont deja preinstallees. Vous allumez, c'est pret (Plug and Play).
Le Pack Gaming : Besoin de performances ? Nos serveurs vous pretent toute leur puissance (RAM, carte graphique, processeur, stockage) pour faire tourner les jeux les plus gourmands en toute fluidite.

Votre avantage
Vous reduisez considerablement le prix d'achat de votre materiel. Vous ne payez que ce que vous utilisez, et votre ordinateur ne devient jamais obsolete.
